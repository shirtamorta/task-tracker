# Task Tracker

Простой бэкенд для управления списком задач на Java.

Я перевел свой старый консольный проект на Spring Boot. Теперь приложение запускает локальный веб-сервер, который принимает HTTP-запросы и сохраняет задачи в базу данных.

## Что использовал:
* Java
* Spring Boot (для запуска сервера и обработки запросов)
* Maven (для сборки проекта)
* Встроенная база данных H2

## Что умеет приложение:
* Создавать задачу (POST /api/tasks)
* Показывать список всех задач (GET /api/tasks)
* Удалять задачу по ID (DELETE /api/tasks/{id})

## Как запустить:
1. Открыть проект в IntelliJ IDEA.
2. Запустить класс TaskTrackerApplication.
3. Сервер запустится на порту 8080.

## Как проверить:
Я проверял работу через программу Postman. Отправлял запросы на http://localhost:8080/api/tasks.

Пример задачи для отправки:
{
"title": "Посмотреть матч Барсы",
"description": "Включить трансляцию в 23:00",
"deadline": "2026-11-20"
}}
